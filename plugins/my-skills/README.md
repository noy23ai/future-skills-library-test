## Finding more

The **Future Skill Finder** plugin, in this same marketplace, lets you search
Future Skills from inside a session and save what you find. Install it too if
you have not.

Saving is instant. Being able to *use* what you saved is not: press **Update**
on **My Skills** — this plugin, not the finder — then start a new session.
Claude reads its skills once, when a session begins.
