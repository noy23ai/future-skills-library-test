# Future Skill Finder

Connects Claude to the Future Skills marketplace and teaches it how to use
that connection: search for a skill, read what its security scan found, and
save it to your Library.

You'll be asked to sign in with GitHub the first time.

## Saving is not installing

A saved skill reaches your repository in seconds, and your **My Skills**
plugin is what puts it on this machine. To pick it up: press **Update** on
that plugin, then start a new session. Claude reads its skills once, when a
session begins.

## This plugin is the same for everybody

Nothing in here is yours — it holds no saved skills and changes only when we
change it. Your own skills live in the *My Skills* plugin beside it.
